# 情境實戰測驗 01

因不知道該網頁的系統架構，先以基本的 web 服務進行情境一些假設

- 可以預先透過壓力測試估算需要的資源，再來活動時間是已經知道的，這樣就可以預先開好機器，避免活動當天雲端供應商沒有機器可以提供
- 如果原本沒有使用 CDN，可以加上來降低負載
- 如果有使用到資料庫，可以確認 connection pool 的設定和查詢效能，以及是否有支援多 replica，是否需要有 read replica 來作讀寫分離
- 如果有接第三方 API，第三方 API 是否能夠承受住這樣的流量
- 要不要加 Redis 和 MQ 都要考量上線時間，還有現有架構，是否有時間完成實作和測試
