# 情境實戰測驗 03

- 已確定網路和防火牆沒有問題的話，先確認 EC2 Instance 本身的狀態，像是 CPU、Memory、Disk 等監控是否有異常，需確認是否有資源耗盡的情況，造成無法建立新的 SSH Session
- 如果原本使用 SSH Key 登入，不排除 `~/.ssh/authorized_keys` 可能遭到修改或刪除
- 如果 Instance 透過 Session Manager 登入，需確認 Instance IAM Role 的權限是否足夠
- 如果 SSH 與 Session Manager 都不能使用，可以透過 EC2 Serial Console 進一步檢查
